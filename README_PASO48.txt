PASO 48 — Dashboard Admin V2

Cambios principales:
- Nueva pestaña Dashboard como entrada predeterminada del Admin.
- Conecta admin_get_commercial_dashboard(), admin_get_inventory_dashboard() y admin_get_v2_overview().
- KPI: facturación, ganancia conocida, ticket promedio, costos faltantes, reposición y sin stock.
- Embudo comercial verificado.
- Facturación diaria.
- Top 10 productos.
- Plan de reposición.
- Rendimiento de campañas y ROAS.
- Centro unificado de alertas.
- Borradores + historial reciente.
- Rangos 7, 30, 90 días y 1 año.
- No consulta datos privados desde la tienda pública: el módulo se carga únicamente en /admin/.

Prueba recomendada:
1. Subir todo el contenido sobre Paso 47.
2. Abrir /admin/.
3. Confirmar que Dashboard sea la primera pestaña.
4. Probar rangos y Actualizar.
5. Verificar Productos y Clientes para confirmar compatibilidad.
